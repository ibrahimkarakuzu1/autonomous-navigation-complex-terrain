# Autonomous Navigation in Complex Terrain

**English**
This project simulates a chaotic Mars surface with random craters and hills. The algorithm dynamically finds "saddle points" and valleys to navigate from Start to Goal with minimum energy expenditure.

## Key Insight / Temel İçgörü
The rover acts like water, flowing through the path of least resistance (valleys) to avoid the high energy cost of climbing.
(Rover, tırmanmanın yüksek enerji maliyetinden kaçınmak için tıpkı su gibi en az dirençli yoldan -vadilerden- akar.)
